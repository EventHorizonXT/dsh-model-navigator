# 开发验收标准

目标是成为可靠的官方通用模型选择器替代品，并以可重复验证的功能优势判断进展。

## 0.3.1 已实现

单入口替换与一键回退；官方状态和提交接口；全局搜索；供应商与真实 ID 标识；收藏和每个供应商的最近成功选择；家族折叠；重复提交、锁定、失败与重连处理。

124 项测试覆盖这些逻辑。首次创建目录和已缓存目录均需验证。接入测试使用宿主实际的 Cordis、槽位、目录与目录解析类，传输和存储通知使用模拟边界。桌面实测另行记录到 TEST-REPORT，不能混同这两种证据。

## 后续验收

| 维度 | 达标条件 |
| --- | --- |
| 官方功能覆盖 | 普通会话、新会话、忙碌会话、目录不可用、凭据刷新和重连均与宿主状态一致 |
| 选择效率 | 收藏/最近模型一键到达；任意模型无需预选供应商即可搜索；带档位模型原子提交 |
| 键盘与无障碍 | 打开后焦点进入搜索；方向键、Enter、Escape、Tab、关闭后焦点恢复；读屏可区分 provider/model |
| 稳定性 | 100 次开关、切会话、重连和失败重试后无新增注册、计时器或订阅泄漏 |
| 大目录 | 1000 模型搜索和滚动无明显卡顿，并记录实测环境与耗时 |
| 视觉 | 深浅色主题、窄窗口、缩放和长模型名均可读；浮层不会被输入框裁切 |
| 专用入口 | 对 Codex 等专用入口有明确的优先级、回退与数据来源说明 |

后续改动先复现或写失败测试，再实现并验证打包产物。每版保留安装包、更新日志和回退说明。只有这些维度逐项验收后，才能宣称全面领先。
