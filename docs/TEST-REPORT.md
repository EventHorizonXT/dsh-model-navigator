## 桌面实机

通过桌面 UI 验证：

1. 插件详情显示 v0.2.1，单模型入口打开后显示当前模型、最近使用、收藏控件、全局搜索与供应商导航。
2. 搜索模型名及真实 ID，结果能区分多个供应商的同名模型。
3. 切换当前会话模型后，按钮与当前模型摘要同步；随后恢复原模型和原推理档位。
4. 停用插件后原生入口恢复且状态一致，重新启用后增强入口恢复。

这些步骤未发送聊天消息或执行模型推理请求。未故意使桌面组件崩溃；崩溃退位由隔离的 SlotCore 回归覆盖。
